# Portafolio Multimedia — Juan Manuel Arango Oliveros

Portafolio web de productor multimedia: diseño de piezas publicitarias y redes sociales, edición y retoque de imágenes, manual de marca, página web, diseño de personaje, animación 2D y motion graphics.

## Estructura

```
index.html          Página principal
style.css           Estilos
img/                Imágenes (optimizadas para web)
videos/             Videos (MP4 con inicio rápido)
fonts/              Tipografía Cascadia Code
documentos/         Manual de identidad de marca (PDF)
```

## Ver en línea con GitHub Pages

1. En el repositorio: **Settings → Pages**.
2. En *Source* elige **Deploy from a branch**, rama `main`, carpeta `/ (root)` y guarda.
3. En un par de minutos el sitio queda en:
   `https://juanmanuelarangooliveros0-code.github.io/Juan_Portafolio/`
